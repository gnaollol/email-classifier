# Email Classifier

A chrome extension that identifies the main topic of the email body. (for GMAIL only rn)
Useful for those who apply to jobs and don't wanna spend 30 seconds reading a rejection letter

# Features
- Detects emails in the inbox
- Classifies job app emails
- Displays badges (interview, reject, offer)

# Stack Used
- JavaScript
